# 🐍 Employee Management System

A simple and practical **Python OOP Employee Management System** created to demonstrate the fundamentals of Object-Oriented Programming through a menu-driven console application.

---

## 📌 Project Overview

This project manages different types of people in an organization using three classes:

- 👤 **Person**
- 👨‍💼 **Employee**
- 🧑‍💼 **Manager**

The project demonstrates how inheritance can be used to extend existing classes and reuse code.

### 🧬 Class Hierarchy

```text
Person
   │
   ▼
Employee
   │
   ▼
Manager
```

---

## ✨ Features

- 👤 Create a Person
- 👨‍💼 Create an Employee
- 🧑‍💼 Create a Manager
- 🔎 Show Person details
- 🔎 Show Employee details
- 🔎 Show Manager details
- 📋 Menu-driven interface
- 🧬 Multilevel inheritance
- ♻️ Code reuse using `super()`
- 🔄 Method overriding

---

## 🧠 OOP Concepts Used

| Concept | Usage |
|---|---|
| 🏗️ Class & Object | `Person`, `Employee`, and `Manager` |
| 🧬 Inheritance | Employee inherits Person |
| 🧬 Multilevel Inheritance | Manager inherits Employee |
| ♻️ `super()` | Reuses parent class constructor and method |
| 🔄 Method Overriding | Each class extends the `show()` method |
| ⌨️ User Input | Data is entered through the console |
